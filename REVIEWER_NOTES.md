## How to Test the App

### 1. Sign In or Guest Mode

- Launch the app
- Sign in with Google or Apple ID using the test account above
- Or create a new account
- **OR** click "Continue as Guest" to test without login

### 2. Explore Main Features

#### Learn Tab (Default)

- Browse 13 categories: Airport, Hotel, Restaurant, Shopping, Transport, Medical, Emergency, Banking, Accommodation, Social, Entertainment, Foundation, Daily Life
- Tap any category to view scenes
- Tap any scene to view phrases
- Use Practice, Dictation, or Shadow Mode for voice practice

#### SOS Tab

- Emergency phrases for travelers
- Tap any phrase to hear pronunciation (TTS)

#### Practice Tab

- Voice practice with different modes
- Requires microphone permission (will prompt on first use)

#### Profile Tab

- View learning statistics
- Edit profile
- Settings

### 3. Permissions Used

- **Microphone**: Required for voice practice (Shadow Mode, Practice Mode)
- **Sign in with Apple**: For account creation and sync

### 4. Notes

- Subscription/Payment features are hidden in this version (coming soon)
- All content is in English and Chinese
- The app works offline for viewing saved phrases
